## Правило двухэтапной передачи владельцу

### Этап A — интеграция владельцем в промежуточный репозиторий

```text
PR_222
→ OWNER_FINAL_REVIEW
→ OWNER_MERGE_TO_eth-macro-data-bridge/main_IF_GATES_PASS
→ POST_MERGE_READBACK_OF_DURABLE_AIFE_CARRIER
→ STOP
```

### Этап B — каноническая интеграция владельцем в AIFE

```text
MERGED_DURABLE_BRIDGE_CARRIER
→ VERIFY_LATEST_AIFE_WORKSPACE_BASE
→ VERIFY_STAGED_ARTIFACT_SHA256
→ VERIFY_TARGET_PATH
→ APPLY_EXACT_ARTIFACT_BYTES
→ UPDATE_REAL_AIFE_REGISTRY
→ RUN_CANONICAL_AIFE_VALIDATION
→ OWNER_INTEGRATION_IN_AIFE
→ STOP
```

```text
STAGING_PR_OPEN_BRANCH_IS_NOT_DURABLE_AIFE_HANDOFF_AUTHORITY=true
SEMANTIC_REWRITE_DURING_HANDOFF=NO_BY_DEFAULT
```

Ни на одном из двух этапов не начинается создание контрактов F2 или работа с исходным кодом сервера F3.
